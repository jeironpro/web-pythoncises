Juegos

01

Adivina el número

Programa genera un numero aleatorio del 1 al 100, le permite 10 intentos al usuario para adivinarlo

02

El ahorcado

Programa que simula el juego del ahorcado. Toma una palabra aleatoria de una lista, muestra el estado inicial del juego, pide y valida una letra al usuario, muestra el estado en cada intento indicando cuando haya ganado.

03

Piedra, papel o tijera

Programa que simula el juego de piedra papel o tijera, el usuario elige una de las opciones y la maquina tambien, finalmente muestra el ganador o empate.

04

Dados aleatorios

Programa que simula un lanzador de dados, pide al usuario un número de lanzamientos, lanza el número de dados indicados y muestra el valor de cada dado, la suma y el producto de todos

Patrones

05

Patrón triángulo

Programa que dibuja un triangulo de astericos

06

Patrón triángulo invertido

Programa que dibuja un triangulo invertido de astericos

07

Patrón rombo

Programa que dibuja un rombo de astericos

Calculadoras

08

Calculadora

Programa que hace la funciones basica de una calculadora, pidiendole al usuario dos operando y un operador, finalmente muestra el resultado de la operación.

09

Calculadora de IMC

Programa que pide al usuario su peso y altura, calcula su indice de masa corporal y muestra el resultado

10

Calculadora de propina

Programa que calcula la propina y el monto total de una cuenta. Pide al usuario el monto de la cuenta y el porcentaje de la propina y muestra el monto total de la cuenta y la propina a pagar

Web y API

11

Convertidor de moneda

Programa que pide una cantidad, una moneda de origen, una moneda destino al usuario, y utiliza la API de frankfurter para obtener los datos de la conversion, finalmente muestra el resultado

12

Acortador de URLs

Programa que acorta una url larga. Pide al usuario la url larga y retorna la url corta

Texto y cadenas

13

Generador de contraseñas

Programa que pide una longitud al usuario y genera una contraseña con esa longitud

14

Generador de chistes

Programa que genera un chiste por petición, muestra un menu de dos opciones al usuario, permitiendo generar un chiste y salir del generador.

15

Historias divertidas

Programa que pide palabras al usuario y genera una historia divertida con esa palabras y se la muestra al usuario

16

Partes de un correo

Programa que lee cualquier archivo que sea de texto y busca los correos electronicos y muestras sus partes (nombre y dominio)

17

Markdown a HTML

Programa que convierte un archivo markdown a un archivo html. Utiliza la libreria markdown para realizar la conversión

Archivos y PDF

18

Combinar PDFs

Programa que une pdfs usando la libreria PyPDF2. Toma los pdfs de un directorio y los une en un solo pdf.

19

Marca de agua

Programa que inserta marca de agua en imagenes

20

OCR sobre PDF

Programa que escanea documentos pdf usando OCR (Optical Character Recognition o Reconocimiento Óptico de Caracteres) que es un tecnica que se utiliza para leer texto desde imágenes o documentos y convertirlos a texto editable

21

Renombrador de archivos

Programa que renombra archivo. Pide al usuario la ruta del archivo y el nuevo nombre, verifica si el archivo existe y lo renombra, de lo contrario muestra un mensaje de error

22

Organizador de archivos

Programa que organiza archivos en carpetas segun su extension. En una carpeta pueden ir archivos de mas de una extensión

23

Convertidor de vídeos

Programa que convierte un video de un formato a otro, permtiendo opcionalmente ajustar la resolución y la calidad del video

Tiempo y hábitos

24

Cuenta atrás

Programa que pide al usuario un numero de tiempo inicial para iniciar un despegue, haciendo una cuentra regresiva del tiempo inicial hasta 1 y posteriormente hacer el despegue

25

Pomodoro

Programa que simula un pomodoro método de gestión del tiempo desarrollado por Francesco cirillo. El programa pide al usuario una lista de tareas separadas por espacios y inicia un temporizador de 25 minutos por cada tarea y un descanso de 5 minutos a cada tarea y en cada 4 tareas el tiempo de descanso aumenta a 15 minutos

26

Reloj alarma

Programa que simula una reloj alarma. Pide al usuario configurar su alarma en un formato especifico, marca la alarma configurada y muestra el tiempo restante (horas y minutos) que faltan para sonar la alarma

27

Reloj digital

Programa que simula un reloj digital, mostrando la hora actual cada segundo.

28

Rastreador de hábitos

Programa que permite al usuario agregar, registrar, marcar y mostrar hábitos diarios. Además, permite ver el progreso de cada hábito registrado.

29

Lista de tareas

Programa que permite agregar, marcar, eliminar y ver tareas, para añadir tarea se pide al usuario el nombre y se guarda con un id que incrementa automaticamente al estilo de una base de datos y además, se marca como incompleta, para permitir al usuario la opción de marcarla completada posteriormente, finalmente la eliminación de las tareas se hacen mediante eliminar el ID.

Visión por computador

30

Detector de caras

Programa que detecta rostros que se posicionen frente a la cámara. Utiliza la libreria opencv para abrir la camara y detectar los rostros.

31

Reconocimiento facial

Programa de reconocimiento facial usando las librerias opencv y face_recognition, compara el rostro de una imagen con el rostro que se posicione frente a la camara y verifica si coincide o no, mostrando el resultado de la comparación en el recuadro del detector de rostros y tambien muestra un aproximado de la distancia entre la coincidencia.

Programa que lee un archivo csv y envia un correo electronico a los correos que encuentre
